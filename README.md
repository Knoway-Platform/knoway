# Knoway

Knoway is a content platform built around claims and discussion.

Instead of only reacting to an entire post, people can engage directly
with specific claims, discuss them in context, and build a track record
as claims are tested against reality over time.

## Status

Knoway is currently under active development.
We are preparing for a private beta.

## Product

- Claim-level discussion
- Contextual responses inside posts
- Reputation and track records
- Support for text, images, and video over time
