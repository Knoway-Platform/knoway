# Changelog

Notable development updates for Knoway.

## Unreleased

### September 2026

#### Product
- Added claim-level discussions linked directly to passages in the original post.
- Added shared post discussions, replies, and in-session draft handling.
- Added inline Agree/Disagree interactions with confirmation and persisted participation states.
- Continued refining publishing, profiles, and the broader reading experience.

#### Infrastructure
- Migrated core post, prediction, and participation data to PostgreSQL.
- Added self-hosted, S3-compatible object storage with signed uploads and versioned media access.
- Added persistent in-app notifications with unread, seen, and read states.
- Continued backend integration work across content, predictions, and reputation systems.

#### In progress
- Expanding object storage toward scalable cloud infrastructure for larger media workloads.
- Completing authenticated media flows.
- Improving prediction extraction, evaluation, and resolution workflows.
- Preparing the product for device testing and the first private beta.
